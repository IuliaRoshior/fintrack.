# Лабораторная работа №5 — ООП в PHP

**Проект:** FinTrack, приложение для банковских транзакций.

## Запуск

1. Распакуйте папку `lab5_php_oop`.
2. Откройте терминал **внутри папки**, где находится `index.php`.
3. Выполните команду:
   ```bash
   php -S localhost:8000
   ```
4. Откройте в браузере: http://localhost:8000

Можно также разместить папку в `htdocs` XAMPP и открыть её через локальный Apache.

**Не открывайте `index.php` двойным щелчком:** PHP нужно запускать через сервер.

Требуется PHP **8.0 или новее**, с обычным расширением `session`. СУБД не нужна.

## Структура

```text
lab5_php_oop/
├── index.php                           Главное приложение и формы
├── style.css                           Стили интерфейса
├── src/
│   ├── Transaction.php                 Одна транзакция и getter-методы
│   ├── TransactionStorageInterface.php Контракт хранилища
│   ├── TransactionRepository.php       Добавление, удаление, поиск, список
│   ├── TransactionManager.php          Расчёты и сортировка
│   └── TransactionTableRenderer.php    Создание HTML-таблицы
├── data/
│   └── seed.php                         12 начальных транзакций
├── tests/
│   └── smoke.php                        Простой тест логики
└── ANSWERS.md                           Ответы на контрольные вопросы
```

## Что умеет

- Создание транзакций через форму с автоматическим уникальным ID;
- Удаление по ID;
- Поиск по ID;
- Сортировка по дате и по убыванию суммы;
- Общая сумма и сумма за диапазон дат **включительно**;
- Подсчёт операций выбранного получателя;
- HTML-таблица с 7 требуемыми полями;
- Хранение операций на время браузерной PHP-сессии.

В целях простоты и безопасности операции записываются в `$_SESSION`, **а не в базу данных**. После завершения/очистки сессии данные возвращаются к стартовым 12 транзакциям.

## Важные особенности реализации

- `declare(strict_types=1)` включено во всех файлах PHP.
- Все свойства транзакции `private`; данные передаются через конструктор.
- Поле `category` добавлено отдельно, потому что **в задании оно есть в HTML-таблице**, хотя не перечислено среди полей `Transaction`.
- `TransactionManager` зависит от `TransactionStorageInterface`, а не от конкретной реализации.
- Класс `TransactionTableRenderer` объявлен `final` и **только** строит HTML-таблицу.
- Комментарии PHPDoc есть у методов и функций.
- Текст выводится через `htmlspecialchars()`, формы изменения данных имеют CSRF-защиту.
